# Go-Live Checklist

- [ ] Production environment, DNS, TLS, secret manager, private network, dan least privilege disetujui.
- [ ] Migration memiliki backup terverifikasi serta rollback owner.
- [ ] Storage versioning, lifecycle, replication, dan CORS dikonfigurasi.
- [ ] Check, integration, build, security smoke, load baseline, backup verify, dan reconciliation lulus.
- [ ] UAT seluruh role lulus; defect critical/high nol.
- [ ] Panduan, SOP, training, support, on-call, alert, dan incident runbook siap.
- [ ] Deployment memakai immutable image digest dan change ticket disetujui.
- [ ] Post-deploy smoke: health → login → aset → fly-to → DXF → maintenance → dokumen.
- [ ] Monitoring intensif 24 jam dan business/technical sign-off terdokumentasi.
