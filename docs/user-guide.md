# Panduan Pengguna XAsset

## Mencari dan membuka aset

1. Masuk menggunakan akun perusahaan.
2. Gunakan pencarian atau filter status/frekuensi di **Data Aset**.
3. Klik **No Asset** untuk detail, atau pilih kartu aset pada peta untuk fly-to.
4. Hijau berarti operational, kuning inspection/overdue, dan merah maintenance aktif.

## Layout dan DXF

- Pilih layout published pada peta. Klik aset untuk melihat posisinya.
- Editor DXF membuat draft dan versi baru; file sumber tidak pernah ditimpa.
- Isi change note sebelum export. Publish/rollback hanya untuk pemegang izin DXF publish.
- Atur zoom, posisi kamera, basemap, dan layer DXF sesuai kebutuhan, lalu klik **Print / PDF**. Dialog cetak browser akan membuka layout A4 landscape; pilih **Save as PDF** untuk menyimpan tampilan peta saat ini.

## Maintenance dan dokumen

- Buka **Maintenance** untuk overdue, due 30 hari, pekerjaan aktif, dan laporan.
- Dari detail aset, buat jadwal lalu pilih **Mulai** dan **Selesaikan**. Isi biaya aktual dan hasil.
- Pilih kategori dokumen sebelum upload. MIME/signature palsu ditolak. Arsip tidak menghapus object permanen.
